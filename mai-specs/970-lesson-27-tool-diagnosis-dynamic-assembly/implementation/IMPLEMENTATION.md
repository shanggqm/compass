## 集成与兼容性

- 模型 Schema 与内部入参分离。审批型参数首次构造后进入既有私有状态；恢复时复用原参数、版本和幂等身份。
- 单参数 SQL 只在当前授权连接内探测和路由；元数据可合并读取，同名关系歧义显式返回。错列建议只包含当前有 SELECT 权限的列。
- 工作阶段工具顺序由入口标志与冻结资产决定；最终回答阶段清空工具及原 continuation。预算阶段选择也持久化，短剩余时限下重放先前步骤保持一致。
- ToolSelection 中的 UUID 同时支持 HTTP JSON 和持久化 JSON。Goal 后续轮次、历史命令读取保留 packs、workflowIds、mcpServerIds。
- 子任务汇报工具参与相同的数量与字节预算；实际执行仍由既有子进程监督器处理。
- 旧 answerProtocol=1/2 按冻结声明与旧域契约执行。旧工作流中的 `{prompt}` 调用继续复用，新增声明使用 `{tasks}`。
- ContextOps 复用现有 JSONB，兼容历史列表结构；共享 HTTP 契约由 Agent 源生成。新增 Prompt 资产随代码交付，部署后按既有 PromptOps 流程发布到新运行代次。
