# 第 24 课 PRD · 动态上下文选择与压缩

分析师在同一个会话里看明细、换问题、继续交班。Compass 需要让模型在短会话直接作答，在长会话接得上前面的约定，也能回到大型工具结果的具体位置。用户照常提问，无需管理窗口、手工复制文件或确认摘要。

## 从两张首页题卡开始

「新建分析」沿用现有建议题交互。点题卡将普通问题填入输入框，可以修改、删除或手动发送。两张题使用相同的生产运行路径，卡片与课程样本只提供开场和验收材料。题面与课堂步骤

| 首页题卡                       | 用户任务                                                                                     | 能看见什么                                                                                                    |
| ------------------------------ | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 一万行渠道日报，先看前五行     | 首问取一万行渠道商品日报，先看实际规模与前五行。下一问核对同一份结果的第 8,001 行。          | 执行详情显示工具实际返回量和预览行数。Agent 能按同一文件引用取得指定行；问一个只有 3 行的结果时直接使用原文。 |

## 使用体验

1. **看大结果。** 工具返回内容较短时，模型收到原文。结果过大时，Compass 保存完整的实际返回内容，给模型状态、规模、少量样本及可读的文件位置。模型可按需要回读指定部分。上游只返回一部分、原件暂时无法落盘或已失去访问权限时，看到相应状态。
2. **自然对话。** 短会话按时间顺序追加问答和工具观察。较长会话按当前问题选择较早历史，最近几轮与当前任务供 Agent 连贯工作。原记录可回看，换题后重新参与选择。
3. **长会话交接。** 历史达到轮数或容量条件之一时，JEV 决定较早完整轮的去留。选择后的请求仍达到容量水位时，Compass 才缩短保留的工具观察并生成历史摘要。恢复时加载既有 system prompt 和默认内置上下文、摘要、预算容纳的最近连续完整轮次及当前任务。最近一轮单独过大时可以回填零轮。
4. **查看与恢复。** 普通聊天无需额外确认。工具预览、文件回读、历史保留与移出、摘要覆盖范围和最近轮数放入已有执行步骤详情。原始会话照常回看；跨轮回读与工作进程接管沿用当前用户的授权。

选择过程优先保证任务推进：每批判断后，当前请求已低于容量水位且可正常发送时即可继续，未判断历史暂时保留，并在需要摘要时一同纳入。较早轮提供的口径、约定与更正，在其他相关轮仍依赖它们时一同保留。完整判断背景超出 JEV 容量时保留候选，再按主请求容量决定是否摘要；历史原件与跨问题恢复能力继续保留。

## 验收标准

| 编号             | 用户或讲师动作                                                                                                                                | 通过条件                                                                                                                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AC-01 工具结果   | 在授权工作区发起小查询，并取一万行、定位第 8,001 行。增加一条超大字段，用另一份实际被上游截断的结果做对照。                                   | 小结果原样进消息。大结果的完整已返回内容可读，模型先收到有界预览，同会话下一 Run 定位的答案与同次结果一致。部分结果如实标记。读页能持续前进。                                                                |
| AC-02 选择与保护 | 历史分别为 7 轮和 8 轮，输入低于水位；另用少轮长消息跨水位。对照 JEV 输入和实际主请求。                                                       | 满足轮数或容量任一条件即选择。最近 3 个完整轮和当前任务得到保护。旧轮按整组保留或移出，主请求按原顺序，工具续轮复用本问题决策。                                                                              |
| AC-03 摘要与回填 | JEV 选择后分别低于水位、达到水位，构造最近四轮可回填和最新一轮单独超额的情况。                                                                | 第一组直接继续，第二组先剪枝再摘要。摘要只含本次保留历史；回填预算可接四轮或零轮，系统与默认上下文按原逻辑装配。                                                                                             |
| AC-06 换题与失败 | 先问退款，使旧仓配轮被移出，再换问仓配。注入 JEV 超时、缺 ID、超大候选和 17 组候选。                                                          | 换题可重新选回原轮；调用失败与超容量组保留，后续按容量压缩；决策请求分批满足现有协议。                                                                                                                       |
| AC-04 业务连续性 | 退款交班跨水位后追问原单、金额、期间、状态、下一步；修改样本中的状态或金额再做一次。模拟 JEV 配置缺失／超时、摘要超时、进程接管与结果源撤权。 | 回答与各自有效样本一致。恢复保留已执行动作和允许访问的材料；选择调用不可用时保留候选并继续；已发出的调用纳入任务总账。分别记录全任务的主模型、JEV、摘要和回读调用与 tokens、耗时，按实际能力区分估算和计费。 |
| AC-05 课程入口   | 桌面和窄屏用键盘预填两题、修改、清空、发送、回看；在 Home 打开方案。                                                                          | 两题都是普通 Chat 入口。可展开真实执行步骤，两种文档格式可读。已发布题面沿现有配置生效。                                                                                                                     |

AC-02／AC-06 补充场景：21 个完整历史轮中，第 2 轮定义口径，第 17 轮引用或更正，最近三轮保护；在需要两批判断时检查两批都能理解并保留必要前提。另验证首批已腾出足够容量时停止后续判断、未判断轮仍可用，以及判断背景超窗时任务沿已有容量压缩流程推进。
