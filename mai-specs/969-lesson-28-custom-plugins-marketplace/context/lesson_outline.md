## **第 28 课：自定义插件与插件市场——打通工具接入、校验、测试、准入与装载**

**本课目标：** 解除新能力接入对 Agent 核心源码发版的强耦合，建设 Compass 自定义插件体系与插件市场，通过“接入—静态校验—撞车检测—沙箱试跑—回放准入—安装装载”全生命周期治理，在开放扩展的同时守住全局工具池的调用质量。

### **核心教学内容**

1. **企业级插件架构选型：** 比较硬编码内置工具、OpenAPI / HTTP 声明式工具插件、受控脚本插件与远程 MCP 插件包的开发门槛、隔离边界与运维成本，确定企业插件分层策略。
2. **统一插件包模型（Plugin Manifest）：** 定义插件元信息、版本语义、包含的能力资产清单（Tool / Skill / Prompt 预设）、鉴权配置模板、网络出站域名白名单、读写与副作用声明。
3. **从后端接口到高可用 Agent 工具的裁剪方法：** 解决直接导入企业 OpenAPI 导致模型调用崩溃的问题——裁剪冗余查询参数、收敛请求体结构、配置响应字段投影（Response Shaping）以过滤无用大 JSON 噪声。
4. **插件静态规范与全局语义撞车检测：** 自动检查 Schema 合法性、嵌套深度、描述字符上限与示例合规性；计算新工具与既有内建/已上架工具的名称及语义相似度，主动阻断易引发误选的近似工具。
5. **插件沙箱连通性与契约测试：** 在隔离测试环境中注入测试凭据发起真实试跑，核验鉴权连通、超时控制、异常状态码映射、响应投影结果及大返回截断行为。
6. **防抢流（Anti-Hijacking）效果准入门禁：** 将待上架插件临时混入标准评测工具池执行离线回放，确保新插件能够精准命中自身目标用例，同时不抢夺核心内置工具的正常调用。
7. **插件市场分级运营与版本治理：** 设计个人草稿 → 提交审核 → 租户私有插件库 / 平台公共插件市场的流转机制；支持工作区按固定版本安装、配置独立连接凭据、灰度升级与异常一键停用（Kill Switch）。
8. **运行时安全装载：** 已安装插件通过统一适配器注册为标准 `RegisteredTool`，自动继承第 27 课的场景化动态组装、按需发现、超时限流与输出预算治理。

### **Compass 实战：建设插件市场与自定义业务插件准入流水线**

**业务场景：**

零售企业的电商运营与供应链团队希望将内部的“大促活动排期服务”“竞品价格监测接口”和“外部工单协同接口”接入 Compass，供分析师在对话中直接联动查询或提单，同时平台管理员要求所有自定义插件必须通过契约检查与防误选测试方可对工作区开放。

**具体建设任务：**

- 设计并落盘插件包数据模型与版本状态机（`draft`、`testing`、`pending_review`、`published`、`deprecated`、`disabled`）。
- 点亮 Compass Web 一级导航「插件 → 全部插件」，交付插件市场浏览页、工作区已安装插件管理页与自定义插件创建向导。
- 实现 HTTP / OpenAPI 声明式工具接入器，支持入参 Schema 定义、服务端加密凭据绑定、请求映射与响应 JSON 关键字段提取。
- 实现五步准入检查器：静态契约校验 → 全局工具名称/语义撞车扫描 → 在线试跑调试台 → 核心基准集防抢流回放检查 → 平台管理员审批上架。
- 将工作区已启用的插件工具无缝接入第 27 课的动态组装器与 `search_tools` 索引；停用插件时安全保护在途活动 Run。
- 课堂完整演练一个存在“描述过宽抢夺 `query_metric` 流量 + 返回体字段过重”缺陷的自定义零售插件，从准入拦截、修复裁剪、通过测试上架到在分析对话中精准调用的全过程。

### **验收标准**

| 验收维度 | 验收要求 |
| --- | --- |
| 零改码接入 | 不修改 Agent 核心代码与重启服务，即可完成自定义外部业务工具注册与调用 |
| 撞车与契约拦截 | 同名工具、超限 Schema、缺失示例或高相似度冲突描述在准入阶段被精准拦截 |
| 在线试跑验证 | 插件工作台可执行真实或沙箱连通性试跑，展示请求耗时、投影后输出与错误诊断 |
| 防抢流回归 | 新插件合入后，既有核心查数与归因基准用例的工具选对率不发生退化 |
| 租户与凭据隔离 | 不同租户私有插件及工作区插件凭据严格隔离，API Key 只写不回显 |
| 动态装载与停用 | 工作区安装启用后立即可被动态路由发现，一键停用后新 Run 立即停止暴露 |

**本课交付：** `Plugin Manifest` 规范、声明式自定义插件执行适配器、五步插件准入检查流水线、Compass Web「插件市场与自定义插件中心」模块、零售扩展插件实战样本。
