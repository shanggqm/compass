# Compass UI 样式规范

适用于 Compass 的页面、弹层、分析消息、组件和交互状态。Web 产品界面以 [设计变量](../apps/web/src/app/ui-system.css)、[共用组件](../apps/web/src/components/ui)和产品内的 [体验指南](http://127.0.0.1:8100/guide) 为准。课程官网沿用相同的可读性和交互要求，品牌页面的布局和视觉细则见 [官网说明](../apps/home/README.md)。

## 基础设计

| 项目     | 规范                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 颜色     | 暖白 `--canvas` 承载页面，白色 `--surface` 承载卡片。正文、辅助信息和主操作分别使用 `--ink`、`--muted`、`--primary`。状态用文字说明，配合图标和语义颜色。 |
| 排版     | 正文 16 px，控件 14 px，辅助信息 12 px，卡片标题 18 px。正文行高约 1.55，代码使用独立的等宽字族。                                                         |
| 间距     | 使用 4 px 基准，按 4、8、12、16、20、24、32 px 组织。标签与控件通常间隔 8 px，同组信息间隔 12 px，卡片内边距通常为 20 px。                                |
| 边界     | 控件圆角 8 px，卡片圆角 14 px。容器用浅色边框区分，输入边界和焦点使用对比度更高的变量。                                                                   |
| 响应式   | 内容在 390 px 宽度下可完整阅读，表单和元数据按空间换行。表格与代码长行在自身容器内滚动，页面维持纵向阅读。                                                |
| 可访问性 | 常规文字与背景对比度至少 4.5:1。交互元素保留键盘焦点环，触屏操作区至少 44 × 44 px。只含图标的操作提供可访问名称。                                         |
| 动效     | 操作反馈优先用约 140 ms 的短过渡。请求进行时同时提供动态图标和文字，遵循 `prefers-reduced-motion`。                                                       |

## 组件与状态

| 组件 | 使用约定                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 卡片 | 以标题和可选说明开头，中间放结果或表单，底部放同一任务的操作。日期、版本等字段用标签和值成组展示。                     |
| 按钮 | 每个操作区突出一个主操作。次要操作使用描边或弱化样式，破坏性操作使用危险样式。等待响应时显示进行状态并防止重复提交。   |
| 表单 | 每个输入有可见标签。帮助文字和错误放在字段附近并建立程序关联。提交失败时保留输入，提供可执行的恢复动作。               |
| 反馈 | 成功和异步进度使用状态区，可立即处理的错误使用告警。空状态说明可用操作，禁用态说明用户可以如何恢复。                   |
| 折叠 | 采用可聚焦的标题行与统一方向图标。次要详情默认收起，需要用户审阅的内容可默认展开。                                     |
| 弹层 | 有明确的标题、确认与取消操作，支持 Esc、键盘焦点限制与关闭后恢复焦点。对写入资产等决定，先提供审阅信息，再由用户确认。 |

长表单使用 `Modal` 的右侧抽屉布局（`placement="right"`）。标题和底部操作固定，字段区域独立滚动，窄屏占满可用宽度。打开时焦点进入首个编辑字段，关闭后返回触发按钮。提交期间显示进度，错误保留在抽屉内。

三级菜单下的页标题使用 [UiPageHeading](../apps/web/src/components/ui/page-heading.tsx)。标题靠左，当前用户可用的页面操作靠右，同排显示。筛选项放在列表上方，字段帮助放在对应表单内。体验指南的「交互演示」提供实例。

管理目录中，同级记录使用固定列并左对齐。类型用文字和图标共同标识；只有真实父子关系使用层级缩进。多字段记录用带表头的表格展示，窄屏允许表格内部滚动。紧凑筛选栏可通过占位文字、默认选项和可访问名称标明用途，筛选控件与同行按钮等高、垂直居中。

## 代码展示

多行源码使用 [UiCodeBlock](../apps/web/src/components/ui/code-block.tsx)。工具栏左侧显示脚本名或入口标识及语言，右侧提供自动换行和复制。等宽正文保留空格与缩进，初始按原始行显示。代码区高度上限为 20 rem，内部支持键盘滚动。切换换行只影响显示，复制使用原始字符串并反馈结果。

生成的源码按纯文本渲染。代码面板承载阅读、选取与复制，执行入口作为业务操作单独呈现。工作流脚本与查询结论分别折叠，保存确认区位于详情之后。

## 演示与维护

登录产品后进入「体验指南」。页面直接演示设计变量、按钮及反馈、代码面板、表单错误、取消与确认。演示确认只改变示例状态。

页面开发先复用已有变量和组件。新增通用变体时同步更新本规范和演示页。交付前核对桌面、窄屏、键盘、请求进行中及失败状态，涉及代码时检查长行、换行和复制。课程展示和产品评审可直接使用体验指南对照。

## 执行过程

Chat 和体验指南共用 `UiExecutionTimeline`。运行过程默认折叠，单行展示最近更新的事件、状态和用时。展开后，思考、旁白、工具、工作流、技能和子任务按开始时间排在同一列。新事件追加，已有事件按稳定 ID 更新。列表在底部时跟随新内容，向上阅读时保留滚动位置。

事件行使用图标、中文类型和一行内容。思考展示模型提供的正文，工具展示具体名称。带详情的行支持键盘独立展开。获授权的查看者可读取正文和脱敏后的工具入参、结果。输入输出使用 `UiCodeBlock` 的局部滚动、换行及复制。并行分组、依赖、MCP 来源和 Sandbox 等执行环境在事件详情中呈现。等待和失败使用文字与语义颜色，减少动态效果模式保留文字状态。

“查询数据”行按可见入参展示数据库操作，例如 SQL 片段或表名。查询完成后在同一行显示返回数量，并摘录首行字段值或连接名。操作和结果分别截断，展开可查看本次调用的入参与结果详情。

收到完成状态后自动收起过程，显示“已完成”和总用时，手动重新展开可回看。焦点位于过程内部时回到折叠按钮。体验指南提供进行中、成功、失败、等待、取消和中断状态。

### 长任务目标与子任务

在输入框开头输入 `/` 或 `/goal` 时显示 Goal 候选，靶心图标与“目标模式”共同标识。上下方向键定位候选，Enter / Tab 选中，Esc 关闭；输入法组词期间保留原输入行为。选中后在输入框上方展示目标模式栏，支持退出并保留正文。发送请求复用长任务能力与目标确认流程。

目标进度与 Todo 面板共用输入框上方的位置，使用靶心图标、目标摘要、状态与轮数，默认收起；鼠标悬停预览，点击或键盘展开管理，Esc 关闭并返回开关焦点。详情展示预算比例、验收项、暂停、恢复、修改和取消，长内容独立滚动；窄屏隐藏摘要中的轮数，在详情内完整显示。修改将焦点带回输入框；请求失败保留原状态并提供重试。准备中和待确认阶段也在输入框上方显示目标摘要，执行确认仍在原轮次内处理。

每个子任务在主流程中占一个事件行，使用 Bot 图标、浅主题色底和边框突出任务名称与状态。点击或 Enter / Space 打开右侧抽屉，窄屏占满可用宽度；抽屉复用 UiExecutionTimeline 展示独立执行过程，默认展开，并以 AnalysisMarkdown 展示完整回答。主流程不展开子任务内部节点。关闭或 Esc 返回原入口，父流程已折叠时返回流程开关。加载、失败、部分完成、失权使用明确文字，短暂失败提供重试，失权清除执行过程和回答。抽屉打开期间持续复核权限，关闭取消请求；再次打开重新读取。`/guide#ui-execution` 同步提供目标面板和并行子任务示例。

## 持久会话与执行确认

会话输入区贴在底部，模型、附件和发送按钮与输入框底边留一档间距。支持背景模糊的浏览器在正常高度下让消息滚到半透明输入框后方，并保留末条消息完整露出的滚动空间。极矮窗口与启用减少透明度的环境使用实色输入框。

已保存工作流在 Workflow 页面查看、改名、启停、删除和导出脚本。删除须经弹窗确认，默认聚焦取消，删除后焦点回到列表标题。启用的动态工作流可按当前工具清单由模型自主调用。旧执行契约显示管理和导出说明。课程案例按钮填入普通问题，焦点回到输入框。

分析会话使用稳定 URL，首次发送后进入服务端 Session。侧栏列表占用「新建分析」与工作空间入口之间的可用高度。会话按更新时间降序排列，按浏览器本地日期显示「今天、昨天、本周、上周、更早」，周一为每周起点。仅显示有会话的分组。标题使用灰绿色文字，单行溢出时截断。滚动接近列表底部时自动加载下一页，也可用键盘加载或重试。历史消息、完整执行过程、图表和保存邀请一次恢复，已保存正文不重播打字动画。SSE 断线显示重连状态并保留内容。

新建分析与已有会话使用独立页面布局，由 URL 中的 Session 标识确定。会话加载、空记录和读取失败都保持会话布局，读取失败提供重试；欢迎文案与候选提示词仅出现在新建页。模型选择按当前用户、租户和工作空间保存在浏览器中，首次发送、追问和刷新保持选择；新建会话继承最近一次选择，返回已有会话恢复该会话的选择。用户主动选择 Auto 时保存 Auto；所选模型不可用时提示重新选择。

进入分析页、会话变更和切回浏览器标签页时刷新会话列表。待生成的自动标题通过单条会话查询更新。

会话标题使用整行可用宽度，溢出时显示省略号。鼠标持续悬停时，长标题平移一次并停在末尾，移开后恢复开头。开启减少动态效果时可通过标题提示查看全文。三点菜单浮在会话行右侧，悬停或键盘聚焦时显示，触屏可以直接点按。改名弹层预填标题，删除弹层默认聚焦取消。自动生成的标题直接更新会话行。

暂停和继续位于分析过程同一行，停止任务位于输入区。`.durable-approval` 在原轮次内展示待确认的安全摘要和截止时间。定时任务确认优先展示变更摘要，分析内容可用键盘展开并按 Markdown 阅读。确认处理后收起卡片，后续进度和结果在原轮次呈现。操作沿用现有焦点样式和禁用规则，请求期间显示提交状态。暂停与停止遇到版本竞争时读取最新状态并有限重试，审批冲突刷新原卡片。待核对保持独立说明，完成取消后执行过程中的工具状态同步更新。窄屏审批按钮换行，产物下载保留原文件名。工作流保存卡展示编排、工具参数契约、试跑入参与结论，从持久投影恢复保存状态与名称，到期后显示邀请失效，保留原分析与脚本。

指标口径选择使用同一组单选项呈现可见候选与“都不合适，我来补充算法”。选择自定义项后显示带标签的多行输入框，填入算法后可在原轮次继续。

对话修订指标时，确认卡逐项列出字段名、当前值和可编辑的新值。字段纵向排列，窄屏也能对照。清空字段或全部改回原值时禁用保存；版本变化时可取消，再按最新定义重新预览。

### 工具与扩展选择

Chat 复用 Modal 展示能力组与个人扩展，原生复选框和文字保持同一行。已选项使用输入区可换行标签，移除按钮有独立可访问名称。MCP 加载状态、实际工具计数、超限与失败在浮层内显示；未知或超限时禁用应用，取消保留此前已应用选择。关闭恢复到入口焦点，390 px 下列表与底部操作均可键盘访问。

ContextOps 工具装配详情复用原生 details/summary，默认展开，Enter / Space 可折叠。常驻、场景、手动来源使用文字标签；历史缺失展示明确提示。PromptOps 的装载通道与治理属性使用只读说明。

## 对话中的指标卡片

查询口径用单选，最多列三个候选，另设「都不合适，我来补充算法」入口。保存建议用多选，最多三项。每项展示业务名称、统计口径、计算公式和复用场景。整卡共用底部操作区，用户主动勾选后可以保存到个人草稿。

## 观测图表

趋势迷你图、哑铃图等数据图表使用 ECharts（`echarts/core` 按需注册，SVG 渲染），颜色取设计变量与轨道色，遵循 `prefers-reduced-motion` 关闭动画。图表容器提供 `role="img"` 与包含关键数值的可访问名称，无数据时显示文字占位。可点击筛选的条形列表、瀑布轨道和表格保持原生按钮或可聚焦行，便于键盘操作。ContextOps 控制台的视觉以 [ContextOps 原型](../mai-specs/971-lesson-26-context-ops/spec/contextops-prototype.html) 为准。

## 技术方案 HTML 阅读版

Compass 所有新增、修订的技术方案 HTML，默认以 Home 中已发布的[第 22 课主方案](../apps/home/public/resources/lessons/22/technical-design.html)和[专题阅读版](../apps/home/public/resources/lessons/22/retail-semantic-assets.html)为视觉样板。阅读器基础样式由项目离线渲染器提供，课程页头、目录、主题与窄屏布局使用[共用阅读版式](../scripts/course-design/reader.mjs)和[样式](../scripts/course-design/reader.css)。新方案默认运行 `node scripts/course-design/reader.mjs <edition.json>`。课程方案在 edition.json 登记数值课号 `lesson`，独立 Feature 可省略课号。已有专用生成器时，在产出 HTML 时调用同模块的 `applyCourseReader`。正文可按课程设计采用表格、时序图、代码和案例。

- **首屏与正文。** 约 1200 px 内容宽，桌面两侧留出 40 px，窄屏 20 px。浅色纸面 `#f9faf7`、墨绿色正文 `#172c25`、强调色 `#245847`。系统中文字体承载正文，代码用等宽字体。首屏展示课号、标题、单句说明和章节目录，有课程架构图时可展开。专题沿用相同字号层次与控件。
- **单文件交付。** 图表在构建时渲染为内嵌 SVG，样式、搜索和代码交互随 HTML 交付。目录、键盘搜索、代码复制和表格局部滚动在断网时可用。Home 会隐藏独立阅读器顶栏，因此正文页头也要能打开目录和检索。
- **内容与生成。** 对照当前代码核对工具签名、配置、数据库归属、失败路径和发布顺序。课堂案例分别标明普通 Chat 实跑、讲师回放、目标或待验事项。维护 Feature 中的 Markdown 和生成入口，重建主方案及相关附录。HTML 的关键数值、示例和图表与各自 Markdown 同源。
- **检查与分发。** 先检查独立文件的桌面和 390 px 窄屏、键盘展开及返回、离线图表与代码。归属具体课次的方案确认后，在 Home 的 `src/lib/lesson-resources.json` 登记 HTML 和 Markdown，并同步 `turbo.json` 的 build/test 输入。运行 `node apps/home/scripts/lesson-resources.mjs --lesson <课号>`，在资源阅读页核对目录、搜索、跨文档链接和下载。长期编辑源留在 Feature 目录。
